# 出勤一打（Chrome 拡張機能）

毎朝、初めてパソコンにログイン（またはスリープ復帰・Chrome起動）した際に、自動で出勤打刻ページを開いて `#btn_punchin` ボタンをクリックする Chrome 拡張機能です。

## 主な機能

- **1日1回だけ自動実行**：その日の初回のみ `https://nara-ta.ddrive.site/teacher_attendance/` を開き、`id="btn_punchin"` のボタンをクリックします。
- **幅広いログイン形態に対応**：
  - PC起動後の Chrome 初回起動（`chrome.runtime.onStartup`）
  - スリープ復帰・画面ロック解除（`chrome.idle.onStateChanged`）
  - Chrome ウィンドウのフォーカス復帰（`chrome.windows.onFocusChanged`）
- **深夜の誤作動防止**：**2:00以降** をその日の朝として判定します（固定）。
- **手動実行＆ON/OFF**：ツールバーのアイコンから、ON/OFF 切り替え・手動で実行ができます。

## インストール方法

1. Chrome のアドレスバーに `chrome://extensions/` を入力して開きます。
2. 右上の **「デベロッパー モード」** をオンにします。
3. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
4. このフォルダ（`/Users/t-cool/Desktop/push`）を選択します。

## Mac で毎朝ログイン時に確実に動かすための設定（任意）

Mac を毎日シャットダウンして朝ログインする場合は、ログイン時に Chrome が自動で起動するようにしておくと確実です。

1. Mac の **システム設定** → **一般** → **ログイン項目と機能拡張** を開きます。
2. 「ログイン時に開く」の `+` ボタンから **Google Chrome** を追加します。

## 注意事項

- 対象サイトにログインしていない状態（ログイン画面にリダイレクトされた場合）は、ログイン完了後に自動で出勤ページへ遷移するとボタンクリックを試みます。
- すでに当日分の打刻が完了している場合、翌日まで再実行されません。
